# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Send a report to support@sparkles-editor.com with:

- the affected version;
- reproduction steps;
- the expected and observed behavior;
- any suggested mitigation.

Do not include production credentials, private keys, personal data, or access
tokens in the report. Acknowledgement should arrive within seven days.

## Supported versions

Security fixes are provided for the latest published release.
